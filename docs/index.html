Visual Studio C++ labs,
done on Linux.

Write code in VS Code (or any editor) on Linux and still hand in a normal Visual Studio solution zip. It builds with Microsoft's real compiler under Wine. No dual boot, no Windows VM, no lab computer.

~/cs-labs
# create a project exactly like File > New > Project
$ vslab new LabPointers_WilsonJ
$ cd LabPointers_WilsonJ_sol

# build with the real MSVC cl/link, then run like Ctrl+F5
$ vslab build        # Debug|x64, writes x64\Debug, .tlog, .vcxproj
$ vslab run

# zip the solution the same way Visual Studio does, ready to submit
$ vslab zip         # LabPointers_WilsonJ_sol.zip

How it works

Genuine Microsoft output where it counts, regenerated to match where it does not, and it tells you which is which.

01

Real MSVC, under Wine

Builds with Microsoft's actual compiler and linker (cl and link) run under Wine, so the exe and build output are genuine, not a GCC stand-in.

02

Real project files

Writes the same files Visual Studio writes: .sln, .vcxproj, and filters. Open the result in Visual Studio and it just loads.

03

A submit-ready zip

Zips the solution folder the same layout Visual Studio produces, so your submission looks exactly like it came from Windows.

Install

Ubuntu 24.04, about 6 GB free. The installer fetches Microsoft's toolchain straight from Microsoft after you accept their license. This project ships no Microsoft binaries.

install
$ git clone https://github.com/Jaron-Wilson/vs-labs-linux ~/vs-labs-linux
$ cd ~/vs-labs-linux
$ ./install.sh      # checks deps, shows the MS license, asks you to type: yes
$ vslab doctor      # confirm everything is in place
CommandWhat it does
vslab new NAMECreates a solution folder like File > New > Project (Console App)
vslab syncPicks up new .cpp/.h files, like Add Existing Item
vslab buildBuilds Debug|x64 with the real cl/link
vslab runRuns the exe like Ctrl+F5
vslab zipProduces the submit-ready solution zip
vslab check REF.zip MY.zipCompares your zip against a reference, file by file

Honest about what is exact

Transparency by design. The README documents exactly what is genuine Microsoft output and what is regenerated to match, so anyone, including a professor, can verify it. The compiled program and build artifacts come from Microsoft's real toolchain; the surrounding project scaffolding is written to match Visual Studio's format.

Contribute & get help

Built and tested on Ubuntu 24.04. Other distributions are untested, and that is exactly where help is welcome. If something breaks, the issue form asks for your distro, where it failed, and your vslab doctor output.
